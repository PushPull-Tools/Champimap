# Champimap — textes du carnet (à relire)

Tous les textes du module **carnet** (niveaux et succès). Source : `app/src/main/java/fr/pushpull/champimap/feature/carnet/CarnetTextes.kt`
(c'est ce fichier qu'il faut modifier ; ce document en est la copie lisible).
Deux tons, choisis dans Paramètres › Affichage › « Ton des messages » : **Normal** et **Sarcastique** (taquin, jamais méchant).
