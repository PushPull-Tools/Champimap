# Champimap — liste de tests (première version)

Pour chaque ligne : ✅ ça marche, ❌ ça ne marche pas (+ une phrase ou une capture).
En cas de problème, Paramètres → Données → **Journal** montre les erreurs (sans aucune position).

## 1. Installation et premier lancement
- [ ] L'APK s'installe (autoriser l'installation depuis le navigateur si Android le demande).
- [ ] Bienvenue : prénom saisi, « Continuer ».
- [ ] Départements : recherche, cocher 1 ou 2 départements, taille affichée.
- [ ] Champimap Connect : « Installer le module » → Android demande l'autorisation → installation OK.
- [ ] Téléchargement : avancement en %, départements, liste qui se coche ; « C'est parti ! » à la fin.
- [ ] (Variante) « Plus tard » : la fenêtre explique ce qui manque, « Continuer » mène à l'accueil.

## 2. Accueil
- [ ] « Bonjour <prénom> », coucher du soleil, lune.
- [ ] Niveau, titre et barre d'XP sous le prénom.
- [ ] Lancer une sortie : cercle qui se ferme, phrase de départ (différente à chaque sortie), toucher pour passer.
- [ ] Bandeau chasse (septembre → février) ; lien « Consulte les arrêtés locaux » ouvre le navigateur.

## 3. Sortie (à faire dehors)
- [ ] Démarrer → « Je suis garé » : la voiture apparaît sur la carte.
- [ ] Notification « Sortie en cours » avec « Marquer un spot » et « Terminer ».
- [ ] Carte : fond de carte (si Connect), trace, position, flèche vers la voiture, distance.
- [ ] « Marquer un spot » : jauge de précision qui s'affine, validation.
- [ ] Fiche spot : nom, coordonnées masquées/affichées, photo du spot, illustration si pas de photo.
- [ ] « Trouvé ! » → Liste → choisir une espèce → poids (+50/+100) → pastilles.
- [ ] « Trouvé ! » → Photo → photo prise et rattachée.
- [ ] « Spot vide » ; « Je suis au pied » ; historique des positions ; « Ajuster la position ».
- [ ] Appui long sur une photo → confirmation → suppression.
- [ ] « Je suis perdu » : coordonnées en grand, flèche, bouton 112 (ouvre le clavier sans appeler).
- [ ] Écran éteint 10 min dans la poche : la trace continue.
- [ ] Terminer (second appui) → Fin de sortie : récap, XP gagnés, succès débloqués.
- [ ] Batterie consommée sur 1 h de sortie : ____ %

## 4. Sortie à plusieurs (2, puis 3 téléphones, Bluetooth activé)
- [ ] Téléphone A : Démarrer → Sortie à plusieurs → QR code.
- [ ] Téléphone B : Rejoindre → scan du QR → connecté (« Avec … · synchro OK »).
- [ ] Un spot ajouté sur A apparaît sur B (et inversement) en moins d'une minute.
- [ ] Une photo ajoutée sur A arrive sur B.
- [ ] Téléphone C rejoint aussi ; les données circulent entre les trois.
- [ ] B s'éloigne puis revient : la synchro reprend.

## 5. Partage d'un spot
- [ ] QR « Lieu seul » : scanné par un autre téléphone → spot ajouté.
- [ ] Fichier `.champi` chiffré (code à 8 caractères) envoyé par Quick Share/Bluetooth → importé.
- [ ] Option « position GPS dans les photos » sur Non : la photo reçue n'a pas de position.

## 6. Autres écrans
- [ ] Stats : périodes, kg, barres, podium ; Carte aux trésors ; Export CSV ; Calendrier.
- [ ] Espèces : recherche (même avec une faute), fiche espèce avec sosies.
- [ ] Mon carnet : niveau, succès en silhouette « ? », ton Normal/Sarcastique dans les paramètres.
- [ ] Intoxication : 15, centre antipoison, urgences (appeler / y aller), bons réflexes.
- [ ] Paramètres : sections + / −, thème, émojis, champignong, verrouillage par empreinte.
- [ ] Preuves « hors ligne » : 0 accès Internet.
- [ ] Sauvegarde : export chiffré puis import sur un autre téléphone.

## 7. Secrets (si tu veux tout trouver)
- [ ] Bouton invisible à côté du prénom.
- [ ] Mode party : tirer fort vers le haut depuis le bas de l'écran.
- [ ] Pluies cachées : 6, 12, 24 appuis rapides dans le vide.
